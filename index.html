About

Built with Web Technologies

EcoScan is a client-side environmental analysis tool that estimates vegetation stress using leaf fluctuating asymmetry (FA) and chlorophyll index from photographs. No server required — all processing happens in your browser.

🎨

Frontend

  • Vanilla HTML5, CSS3, ES6+ JavaScript
  • CSS Custom Properties (design tokens)
  • Playfair Display + DM Sans typography
  • Reveal-on-scroll animations
⚡

Analysis Engine

  • Canvas API for image processing
  • Leaf segmentation algorithm
  • White-background color calibration
  • Seeded PRNG for deterministic results
🗺️

Mapping

  • Leaflet.js interactive maps
  • Custom SVG markers (teardrop + hexagon)
  • Layer switching (FA / Chlorophyll)
  • LocalStorage + embedded dataset

The Method

Science Meets Technology

🔬

Fluctuating Asymmetry

Fluctuating asymmetry refers to small random deviations from perfect symmetry in leaves. It indicates accumulated environmental stress over the growing season — higher asymmetry means poorer environmental conditions.

🌱

Chlorophyll Index

Calculated from color channels in leaf photographs. Shows current plant health — pale or yellowing leaves indicate lower chlorophyll levels and potential stress.

🌍

Interactive Map

Two independent map layers: FA layer (chronic pollution) and Chlorophyll layer (current status). Together they provide a complete ecological picture.

Methodology

Scientific Foundation

The fluctuating asymmetry method was developed by V.M. Zakharov and is based on measuring small random deviations from bilateral symmetry in organisms.

FA Parameters

  1. Width of left and right leaf halves
  2. Length of second-order vein
  3. Distance between first and second-order vein bases
  4. Distance between first and second-order vein ends
  5. Angle between main vein and second-order vein

Chlorophyll Index (ChI)

Calculated from photograph color channels with white background calibration:

ChI = (G − R) / (G + R)
photo NDVI analog (range: −1 … +1)

Final stress index:

Stress = (FAnorm + (1 − ChInorm)) / 2
0 = perfect health, 1 = critical stress
